# 粘贴课表导入（保底通道）

**一句话**：教务接口、会话、学校皮肤全都不灵的时候，学生手上还剩一张能在浏览器里看见的课表 —— 这条通道就吃那张课表。

## 什么时候用它

| 症状 | 以前 | 现在 |
|---|---|---|
| 教务页白屏 / 一直转圈 | 卡死在导入页 | 复制课表 → 粘贴导入 |
| 学校改版，`print-data` 字段变了 | 取到 JSON 但写不进课表 | 复制课表 → 粘贴导入 |
| 会话怎么都过不去（验证码/单点） | 无法导入 | 复制课表 → 粘贴导入 |

不替代主路径：`打开融合门户登录` 仍然是第一选择，粘贴导入是入口下面的一行小字。

## 能吃三种输入

1. **表格 HTML** —— 电脑上课表页 `Ctrl+U` 看源码、另存网页，或整页复制过来（认 `<table>` / `<td>` / `<tr>`，带 `rowspan`/`colspan` 更准）。
2. **制表符表格文字** —— 手机浏览器里长按全选复制，粘贴进来（Chrome 复制表格时单元格之间是 `\t`）。
3. **一行一课清单** —— Excel 导出、或教务的列表视图，`课程名 教师 地点 周一 第1-2节 1-16周` 这样一行一条也能认。

三种输入走同一个解析器：`school/ScheduleGridImport.kt`（纯 Kotlin，无 Android 依赖，JVM 单测直接跑）。

## 解析器干的三件事

1. **把 `<td rowspan colspan>` 还原成行 × 列矩阵** —— 真实网格，不是拼字符串。跨行跨列的那格在它覆盖到的每个位置都出现同一段文字。
2. **定位时间格**：表头里的「星期一…星期日」决定星期，首列的「第N节 / 第几大节」决定节次；首列是空的时候（浏览器复制 `rowspan` 表格的特征）沿用上一行的节次跨度，**不自作主张 +1**。
3. **抠字段**：周次、地点、教师、课程名。周次认 `1-16周`、`1-5,7-11单周`、`1-16周(双)`、`1-10周除5`、`2、5、8周`、`全周`。

认不出的格子**不静默丢掉**，在预览里逐条报出来（"第3节 星期三：「……」"），学生一眼能看出是哪一格。

## 已适配的三种页面形态（都是真实存在的，见 `ScheduleGridFormatsTest`）

| 形态 | 特征 | 专门处理的地方 |
|---|---|---|
| 正方新版（eams5/UWP） | `<div>` 逐行、周次带方括号 `[01-16周]`、表头有「上午/下午」整行（`colspan` 铺满） | 块级开标签删掉、闭标签换行；整行分隔跳行 |
| 旧版正方 | 节次列 `1-2`、课程格 `rowspan` 跨行、`<br>` 分隔字段 | `expand()` 还原 + 按 key 去重 |
| 强智 / URP 复制文本 | 首列「第一大节」、一行里空格分隔 `课名 老师 周次 地点` | 「第X大节」×2 换算；行尾 2~4 个汉字认老师 |

其它学校的课表只要还是「星期做表头 + 节次做首列」这一族，就能认；
**产品和注册表口径不变：只支持中石大克校区**（`SchoolRegistry` 里只有 `cupk`）。

## 四个坑（改这个文件之前先读）

- **周次正则必须带 `(?<!\d)`，且数字与「周」之间不允许空白。** 否则「逸夫楼201 \t 周一」里的 `01\t周` 会被当成"第1周"，地点被啃掉一截、星期也丢了。
- **`rowspan` 表格复制出来，第二行首列是空的。** 这时节次要沿用上一行，顺延会整门课错位。
- **块级标签不能「开闭都换行」。** `<div>` 换成换行、`</div>` 也换成换行 → 两个 div 中间多出空行 →
  被当成「一格塞多门课」拆开，**课名/教师/地点各变成一门课**（实测：一门高数裂成两门）。
  正确做法是开标签删掉、闭标签换行。
- **裸名教师必须在地点抠掉之后再认。** 整行空格分隔时行尾 token 可能是「C3-105」，
  先认老师会把教室号当人名；先抠地点，再看行尾。
- **键盘会把预览和按钮顶出屏幕。** 页面必须 `imePadding()` + 纵向滚动，否则用户打完字看不到「认出几门课」。

## 落库

解析输出已经是 activities 字段（`courseName/weekday/startUnit/endUnit/weekIndexes/weeksStr/room/teachers`），
所以走 `SchoolImportPolicy.activityAllowlist` 之后**直接** `EamsLocalImport.import`，不再过学校 adapter
（再过一遍会被当成 `print-data` 再转一次）。节次由 `PeriodTableStore` 换算成钟点。

空内容 / 一门课都没认出来时 `import` 返回 `imported=false`，**不覆盖**已有课表。

## 验收

```bash
# 解析层（8 条）：矩阵还原、rowspan 复制、四类周次写法、认不出要报警、白名单放行
./gradlew :app:testDebugUnitTest --tests '*ScheduleGridImportTest*'

# 落库层（2 条，Robolectric）：真写进 Room、节次换算成钟点、周次串落库、空内容不覆盖
./gradlew :app:testDebugUnitTest --tests '*SchedulePasteImportTest*'
```

设备侧（模拟器）已验证：入口 → 页面渲染 → 粘贴纯文本 → 预览报出认不出 → 按钮禁用态。
中文输入无法用 `adb shell input text` 注入（ASCII only），所以**正例走 Robolectric 那条**，设备上只验 UI 接线。
