## 2. 帧质量脚本（这是本方案的核心验收工具）

新增 `tools/check_frames.py`（系统 python3 + Pillow 即可，本机已有）：

```python
#!/usr/bin/env python3
"""校验烘焙出的帧序列：闭合、叠影、体积。用法：python3 check_frames.py <帧目录>"""
import sys, os, json
from PIL import Image, ImageChops, ImageStat

d = sys.argv[1]
meta = json.load(open(os.path.join(d, "meta.json")))
n = meta["frames"]
frames = [Image.open(os.path.join(d, f"f{i}.png")).convert("RGB") for i in range(n)]

def diff(a, b):
    return ImageStat.Stat(ImageChops.difference(a, b)).mean[0]

consec = [diff(frames[i], frames[(i + 1) % n]) for i in range(n)]
wrap = consec[-1]                      # 帧 n-1 → 帧 0
avg = sum(consec[:-1]) / (n - 1)
size_mb = sum(os.path.getsize(os.path.join(d, f"f{i}.png")) for i in range(n)) / 1e6

print(f"帧数 {n}  平均相邻差 {avg:.2f}  闭合差 {wrap:.2f}  总体积 {size_mb:.1f}MB")
ok = True
if wrap > avg * 1.5:
    print(f"✗ 不闭合：闭合差 {wrap:.2f} > 平均相邻差 {avg:.2f} × 1.5，桌面每轮会硬跳一次"); ok = False
if max(consec) > avg * 3:
    print(f"✗ 存在跳帧：最大相邻差 {max(consec):.2f} > 平均 × 3"); ok = False
if size_mb > 6:
    print(f"✗ 体积超标 {size_mb:.1f}MB > 6MB（颗粒强度或分辨率要降）"); ok = False
if min(consec) < 0.15:
    print(f"⚠ 最长静止变化 {min(consec):.2f} 过小：可能有几帧几乎一样，等于浪费帧预算")
print("PASS" if ok else "FAIL")
sys.exit(0 if ok else 1)
```

**通过线**：闭合差 ≤ 平均相邻差 × 1.5；最大相邻差 ≤ 平均 × 3；总体积 ≤ 6MB。

## 6. 发版前的三条硬核验

按 `docs/RELEASING.md` 走，另外本方案额外要求：

1. **APK 增量 ≤ 300KB**：`unzip -l` 对比上一版，shader 源码与参数表不能吃包。
2. **首启不卡**：清数据 → 首次进入外观页，GL 初始化（含 program 编译）≤ 400ms，期间不黑屏。
3. **回滚可用**：把 `shader_ok` 手动置 false，图库仍能用经典款，不崩。
