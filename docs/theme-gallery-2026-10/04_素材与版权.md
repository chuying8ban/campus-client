# 04 · 素材与版权

## 1. 素材三种来源，各自的位置

| 来源 | 用在哪 | 授权 | 注意 |
| --- | --- | --- | --- |
| **自写 GLSL**（程序化） | 缓流 / 光晕两大类，共 18 款 | 我方原创 | 学思路可以看 Shadertoy，但 Shadertoy 默认许可是 **CC BY-NC-SA 3.0**：禁止商用、要求同协议。**一行都不许直接拷**，自己重写并留设计记录 |
| **AI 生成静图** | 静图微动 6 款 | 看具体平台条款（多数允许商用，需留存生成记录） | 不要生成"二次元角色"（同人风险）；不要模仿在世艺术家风格名 |
| **免版税素材库** | 备用 / 少量补位 | Pexels / Coverr / Mixkit：免费商用、无需署名 | Pexels 许可禁止"原样转售"与"做成竞争性图库服务"；本 App 内嵌使用不属此列，但仍建议署名（`author/license` 字段已有） |

**明确不可用**：
- Wallpaper Engine 创意工坊的壁纸 —— Steam 订阅协议限定在 Steam 客户端内使用，不能打进 APK 分发。
- Unsplash 图片用于"壁纸/图库类服务" —— 其许可禁止"用它搭建竞争性服务"，本 App 的在线图库有被解释为竞争性服务的风险，避开。
- 任何搜索引擎/壁纸站抓来的图（`ArtLibrary.kt` 顶部注释已写：侵权）。

## 2. AI 生成静图的规格

| 项 | 要求 |
| --- | --- |
| 尺寸 | 3840×2160（横，小组件与 App 全屏共用）+ 1920×1080 压缩版 |
| 色彩 | sRGB，无嵌入 ICC；不要 HDR |
| 构图 | 画面中心 40% 区域必须是**低对比、无主体**（那里放日期和文字）；主体在左右两侧或边缘 |
| 边缘 | 四角不能有高频细节（会被圆角裁掉，且暗角会压死） |
| 主色 | 每张 ≤ 4 个主色，饱和度整体 ≤ 70%（高饱和在小组件上很廉价） |
| 禁止 | 文字、水印、人脸特写、单独一只眼睛、箭头/图表类的图形 |

**prompt 模板**（可直接用，重点是"低对比中心 + 无硬边 + 柔光"）：

```
{mood} atmospheric background, extremely soft focus, no hard edges,
cinematic depth of field, gentle volumetric light from {direction},
{muted palette} muted color palette, low contrast center area,
subtle film grain, no text, no people, no logos, ultra wide 16:9
```

参考对照组（8 个 mood，对应 6 款静图 + 2 款备用）：

| id | mood 关键词 | 色调 |
| --- | --- | --- |
| `dune` | misty desert dunes at dusk, wind-blown sand haze | 沙金 + 灰紫 |
| `library` | old library at night, single warm lamp, shelves blurred | 琥珀 + 深棕 |
| `rain_gate` | campus gate in rain, sodium lights blooming | 青蓝 + 橙 |
| `snow_field` | snow field before sunrise, faint blue gradient | 冷蓝 + 白 |
| `forest_fog` | pine forest in fog, layered silhouettes, no detail | 墨绿 + 灰 |
| `city_night` | city skyline at night, bokeh lights, heavy blur | 深蓝 + 暖点 |

## 3. 每款的交付物（一个主题 = 一个目录）

```
assets/themes/liquid/
├─ theme.json          # 参数（见 02 §4.4）
├─ base.png            # 可选：静态底图（程序化款不需要）
├─ thumb.png           # 320×180 预览（烘焙一次生成，手做也可）
└─ PROVENANCE.md       # 来源记录（见下）
```

`PROVENANCE.md` 必填：

```markdown
- 类型：程序化 / AI 生成 / 免版税摄影
- 作者：<GitHub id 或 生成模型名>
- 生成日期：2026-10-20
- 工具与参数：<模型 id + prompt 摘要 / 素材 URL + 下载日期>
- 授权：原创 / CC0 / Pexels License / 商用授权（编号）
- 是否含人物或商标：否
```

## 4. 上线前的版权自查（逐条打勾）

- [ ] 每个程序化主题的 GLSL 是本仓库自己写的，`git log` 能找到首次提交
- [ ] 每个 AI 图都有 `PROVENANCE.md`，含模型与日期
- [ ] 没有任何文件来自 Wallpaper Engine / Unsplash / 壁纸站
- [ ] 图库里没有一次元/二次元角色形象（哪怕"很像"）
- [ ] 服务器 `catalog.json` 里每条的 `author` / `license` 字段都填了真值，不是占位符（`ArtRepo` 有默认值 `"校园助手"` / `"原创生成"`——**靠默认值就是造假**，必须显式写）

## 5. 素材数量与节奏（别一次上 30 款）

- P1 只做 **3 款样张**：`liquid`（液态）、`dusk`（地平线光）、`dune`（静图微动）。这三款覆盖三种技术路线，用来验证画质天花板。
- P2 扩到 **12 款**（缓流 6 + 光晕 3 + 静图 3）。
- P3 补到 **24 款**。
- 每加一款的成本 ≈ 1 天（写 shader + 调参 + 三档真机验收）。**不要为了"量大"降低单款质量**——24 款精品比 90 款换色强。
