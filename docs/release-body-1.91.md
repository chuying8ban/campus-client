校园课表与学习客户端 —— 面向中国石油大学（北京）克拉玛依校区教务系统的 Android 客户端：课表、早晚自习、任务、公共学习资源、选修课余量监控，外加外观主题与看板。

**非官方项目**：由一名学生个人开发，和学校教务处及任何学校官方系统不存在隶属、授权或背书关系，风险自负。

### 这一版（1.91）：所有人的包现在完全一样，管理页搬到了浏览器里

- **不再分「公开版 / 作者版」**：以前作者那台设备装的是另一只包、号还比公开版高一号（只为多出一个管理入口）。现在这种做法取消了 —— **所有人的安装包、安装方式、更新通道、功能完全相同**，一个包覆盖全部用户。
- **App 里不再有任何管理入口**：那一页从包里摘掉了（此前它随包发出去、只是普通用户看不到）。作者现在用浏览器打开 `https://study.ccbase.top/admin/`，用只有本人知道的服务器口令登录；**普通用户看不到、也进不去**，这一页对你们没有任何影响。
- **更新通道收敛成一条**：所有版本都读同一份 `/updates/manifest.json`，不再有"作者走另一条通道"这种内部差异。
- 「我的」页顺手清掉了随管理入口一起留下的残留项，页面更干净。

### 安装

1. 下载下面的 `campus-1.91.apk`；
2. 手机上允许一次"安装未知来源的应用"，装上即可，不用连电脑；
3. 首次打开用你的教务账号登录（学号 + 密码）。

**你需要有这个校区的教务账号**：课表导入、余量监控、学习库都要用它登录；没有账号的话装上是个空壳（离线那半——节次表、自己手录的课与任务——照旧能用）。

安装包用固定的一把密钥签名，所以以后的新版能直接覆盖安装、本地数据不丢；App 里「我的 → 检查更新」也能收到新版本。

### 你的数据去哪了

登录时学号与教务密码会经 HTTPS 发给作者的后端服务（`study.ccbase.top`），并以**加密形式保存在服务器上**，用来每天代你登录教务、读课表、生成计划、查选修课余量；你随时可以在 App 的「我的」里一键删掉这份凭据。服务端**不记录口令**：校验失败的日志不回显提交值，登录成功或失败只记学号与来源 IP（用于失败计数与限流）。不想把密码交给别人，就 clone 仓库、把 `apiBase` 指向你自己的服务再自己构建。详见 README 的「下载安装」与「内置数据与隐私」两节。

自己上传的背景图**只在手机上**：走系统照片选择器（不申请任何存储权限）、存在 App 自己的目录里、不上传服务器、不进任何备份；换回默认时那张图会被删掉。

（近期用浏览器打开这个域名可能被拦、显示一张合规提示页；那是域名侧的状况，App 走的连接不受影响。）

### 选修课监控（只监控，不代抢）

「监控」只做余量监控与提醒：**它不会替你选课，也不会代你向教务系统提交任何选课请求** —— 发现余位时它做的唯一一件事是在你手机上弹一条提醒，剩下的你自己操作。选课这件事的最终结果始终由你在教务系统里的操作决定。

你的监控清单**按账号隔离**：你盯哪些课只有你自己看得到，别人删不掉、也覆盖不了。它可能因教务系统改版、限流或接口变化而失效；由此造成的任何后果（含错过选课时间）由使用者自行承担，作者不负责、也不提供保证。

### 这个包是什么

- **单包**：所有人的包一致，含主题与背景、课位监控与看板；**App 内不含任何管理入口**（管理页搬到浏览器里，只有作者本人能用）。
- 面向的教务系统：中国石油大学（北京）克拉玛依校区（`eams.cupk.edu.cn`），只读读取当前登录用户自己的课表数据。
- 校验：APK `sha256 = {{SHA256}}`，大小 `{{SIZE}}` 字节；**签名证书** SHA-256 前 8 位 `6eb42692`（固定密钥，与 1.23 → 1.90 同一张证书，所以以后的新版能直接覆盖安装）。
