# 全国高校导入推进清单

## 第一阶段：已执行，尚未发布
- 学校配置 SchoolProfile：学校标识、本研类别、官方 origin、入口和适配器 ID。
- SchoolRegistry：目前只登记 CUPK 本科；未登记学校不能冒充支持。
- 导入页支持学校搜索/选择，并显示未适配提示。
- SchoolWebLogin 导航与提取绑定当前学校 HTTPS origin，拒绝外域、用户信息 URL 与非标准端口。
- 树维适配器负责 print-data 请求路径与白名单活动转换；仍通过既有 preview/local-import 通道。学期脚本、取数脚本与请求路径已移到适配器接口，树维实现独立；正方/强智尚无真实协议实现。
- 会话 consent 按学校 ID 隔离，兼容 CUPK 旧配置，忘记登录按学校 origin 清理。
- CUPK 登录页特殊布局补丁不对其他学校执行。
- 验证：651 项测试全部通过，assembleRelease 成功；合成数据仅验证解析与安全边界，不代表新增学校实测。

## 第二阶段：树维复用
需要至少一所其他树维学校授权测试用户，在官方页面登录后验证真实课程、周次、时间、学期、导入预览、原课表保护。不能靠登录页厂商标识推断可导入。不得索取聊天中的密码或 Cookie。尚未取得真实样本，未登记新增学校。

## 第三阶段：正方/强智
先取得脱敏课表导出样本和官方页面结构，分别实现学期选择、请求/页面解析、统一数据映射、本研与作息配置。每一系统先验一所学校，再扩版本。不得把树维 fetchScript 直接套正方/强智。

## 当前限制
自动取数仍是树维本科 print-data；通用作息模型尚未实施，CUPK 既有本机自习规则尚未完成跨校隔离。因此目前不能启用其他学校。不要发布为全国高校已支持。当前 release APK仍标既有版本，不作为更新分发。
