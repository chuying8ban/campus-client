# 校园助手 3.4.28

## 「找到 N 张」停在第一页

那一行原来优先显示 `stage`，而 `stage` 是**第 1 页请求回来时写死的一句话**
（`"「原神」找到 10 张动图"`）。往下滑触发的 `loadMore` 只往 `live` 里追加数据，
从来没回去改它 —— 于是列表越滚越长，数字一直停在 10。

改成：**有内容时，数量一律以实际列表长度为准**，`stage` 只在"什么都还没显示"时当作过程提示。
顺带把状态写清楚：加载中显示「正在加载更多…」，有没有下一页分别显示「往下滑继续加载」/「已经到底了」。

App 主题库和小控件主题库是同一屏（`ArtGalleryScreen`），一处改完两边都对。
