# 校园助手 3.4.30

## 登录入口改成融合门户（主）
导入课表这一步现在走学校的**统一身份认证（CAS）**，也就是大家平时进融合门户那个登录页：

- 账号密码不变，就是门户那套；
- 认证成功后由教务自己下发会话，读课表的能力没有任何变化；
- **门户打不开时可以一键切回教务直登** —— 登录页下面有一行「改用教务直登 / 改用融合门户」，随时切换，不用等发版。

安全边界没动：WebView 只放行 `eams.cupk.edu.cn` 和 `cas.cupk.edu.cn` 两个域名（精确匹配、必须 https/443、不许带 userinfo），别的 `*.cupk.edu.cn` 一样拦。密码仍然只在学校的登录页里输入，App 不读输入框。

## 记住密码 / 自动登录
勾了「记住密码」的同学，到这里会**自动把账号密码填好**，你只需要补验证码 —— 为什么不能全自动：门户的登录页强制验证码（`enableCaptcha=Y`），自动提交只会被驳回，还可能白攒失败次数。

如果会话还没过期，重新进教务是直接通过的（CAS 单点登录），根本不会弹登录页。

## 备用入口
教务直登那条路径原样保留，只是不再默认走。之前能用的人不会因为这次改动被挡在门外。

## 提建议可以带图
「我的 → 提建议」多了一个「＋ 加张图」：从相册选一张，客户端缩到长边 1280、JPEG q80，通常 80~250KB。带图能省掉大量来回描述。后台能看到原图和文字一起。

## 后台可以写公告了
后台新增「公告」栏：标题、正文、链接、图片地址，发布后用户下次打开 App 会弹一次。这次登录方式的变化就是用这个通道通知的。

线上 sha256 见 release 页。
