# 校园助手 3.4.38

## 文字颜色拆成两套
之前一个设置管两处：在 App 主题页挑个黑色，桌面卡片上的字也跟着变；反过来也一样，两个页面互相打架。

现在是两个独立设置、两个存储键：
- 「App 主题」页那一排 → 只写 `text_tint`，只改 App 里的字；
- 「桌面小组件」页那一排 → 只写 `widget_text_tint`，只改卡片上的字。

标题也分开了（「App 文字颜色」/「小组件文字颜色」），底下那句说明直接写明"不影响另一边"。

## 可读性各管各的
- App：改了字色后，背景层自动压幕（深字压白幕、浅字压黑幕）；
- 小组件：卡片上有一层遮罩，只在你挑的颜色和底板撞色时才显示，不撞色就透明不挡图。

两边都用同一个判定算法，但**各读各的设置**。

线上 sha256 见 release 页。
