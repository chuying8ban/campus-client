# 校园助手 3.4.33 —— 看不见的字

## 为什么看不见
你挑了「白」字（或者浅色主题本身文字就浅），底又是一张亮照片 —— 白色字压在亮图上，等于什么都没写。

## 现在怎么改
落笔之前过一道**对比度闸**（WCAG 大字线 3:1）：

1. 你挑的颜色够看 → 就用它，不改你的选择；
2. 不够看 → 退回这套底板上原本的字色；
3. 原本的也不够看 → 按底板明暗给纯黑/纯白。

所以「黑/深灰/白/暖白/淡紫…」这些都还能选，但**永远不会选出看不清**。小组件那侧走的是同一套闸。

## 背景图那一层
照片背景的遮罩原来是上下厚、中间薄到 10%。10% 在亮图上基本等于没有，标签就糊进去。现在中间最小 20%，上下仍更厚 —— 图还在，字能读了。

## 守卫生效
新增 `TextTintContrastTest`：白字配浅底、黑字配深底、三级字、小组件 ARGB 版本，逐条断言对比度。

线上 sha256 见 release 页。
