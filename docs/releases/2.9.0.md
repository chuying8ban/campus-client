# 校园助手 2.9.0

## 1. 桌面小组件：完整预览

「外观 → 桌面小组件」最上面现在是一张**按 4×2 画的完整卡片**，不再是半截或者只有配色块：

- 底图走的是真机上同一个绘制函数（`WidgetArt.background`），不是另画一个仿的
- 文字用的是你**真实课表**（正在上/下一节、时间、地点、后几节），不是假数据
- 换配色、切图片主题、开「随时间」，上面立刻跟着变

下面的小字写清楚了：真机上格子更窄时会自动收起日期/周次 —— 预览是最宽松的那种格子。

## 2. 小组件：早晚自习 + 自己的日程

- **早晚自习**进卡片了（`07:20–08:00 早自习 · 操场`），跟课程排在同一条时间线上，按钟点插入。
- **自建日程**也进卡片，但和课程**分得开**：日程那一行前面有「日程 · 」前缀、整行用主题强调色；
  课程还是正文色。别人一眼能看出哪个是课、哪个是你自己排的。
- 顺手清掉一个老 bug：卡片曾显示「还有 19 件任务」。任务系统你已经取消，但库里还留着旧记录，
  小组件还在数它。现在小组件根本不读任务表（并加了单测钉住：页脚永远不许出现"任务"）。

## 3. 日程规划（新功能）

今日页往下一点有一块**今日日程**：

- 空着的时候是一行「＋ 加一条日程，例如「16:00 交实验报告」」
- 点进去填：内容 / 日期 / 开始 / 结束（可空）/ 备注
- 今日日程里点一下 = 勾完成（划过一条线），右上「全部 ›」进日程规划页，可按天看、改、删

关键设计：日程是**单独一张表**，不并进课表。所以你下次从教务导课表，日程一条都不会被冲掉。
显示上跟课程同一套骨架（左列时间、右边内容），但日程带「日程」标签 + 强调色。

## 4. 动态主题

**App**：外观 → 页面背景 → 下方新开「动态主题」，四种，缩略图里就真的在动：

- 极光：三条彩带缓慢流动
- 星轨：星点在闪 + 一条银河慢慢横移
- 呼吸：光晕一起一伏
- 落樱：花瓣往下飘

都是 Canvas 现画（不是视频），跑 30fps、切到后台自动停 —— 比一张循环动图省得多。

**桌面小组件**：「配色」里多了「随时间」——小组件的"动态"只能是这一种，因为 Android 桌面
不让小组件跑动画。做法是让每次重画（每 30 分钟一次）的颜色跟着外面的光线走：清晨冷蓝、
上午青、正午亮蓝、午后暖橙、黄昏红紫、夜里深紫、凌晨近黑。也就是说，同一张卡片一整天在慢慢变。

## 5. 图库 976 → 3642 张

入口卡片上现在写的是真实条数。这次把精选清单从 976 张扩到 3642 张（IP、题材、场景三层都扩了），
图仍然不入包 —— 清单里给的是服务器代理地址，点开哪张下哪张。

## 已知边界

- 小组件动画：见上，Android 桌面不支持，所以做的是"随时间变色"。
- 日程暂不支持重复（每天/每周）；需要的话下次加。

## 6. 课表：没课的那天不再消失

课表原来只画"有课的星期"（常见 5 列），周末没课整列就没了，看着像这天不存在。现在固定
**周一到周日 7 列**，空的那天留着空格；列表视图里没课的那天也会显示一行「这天没课」。

表头因为变窄了，"周一"改成单字"一"，今天的列仍然用强调色标出来。

## 7. 小组件加不到桌面：给了手动步骤

「一键添加到桌面」用的是系统 API，国产 ROM 经常直接挡掉（小米/HyperOS 尤其）。所以现在：

- 点「添加到桌面」如果系统不接受，**自动把手动步骤摊开**，不给你一个点了没反应的按钮
- 手动三步写在卡片里：桌面双指捏合 → 小部件里找「校园助手 · 今日课表」→ 拖到空位
- 旁边还有「打开应用设置」，有些机型要先允许「桌面快捷方式」才会在列表里出现
