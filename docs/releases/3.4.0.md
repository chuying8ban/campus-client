# 校园助手 3.4.0

## 1. 动态主题也能调浓淡

之前「图片浓淡」只对自选照片生效，动态主题（预设里的极光/落樱，以及自己传的 GIF/视频）根本没有这一档。
现在三种背景都吃同一个滑块（标签按类型显示「图片浓淡 / 画面浓淡」）：

- 预设动效：动效层按浓淡半透明盖在底色上，淡了就是淡了；
- 自己的动图/视频：不透明度照旧，**遮罩厚度也跟着浓淡收敛**——调淡之后不再是一块灰玻璃。

## 2. 图库新增「动图」板块

搜索框下面多了两个板块：「全部」（静态+动态混排）和「▶ 动图」（只问会动的）。
App 背景图库（竖图）和桌面小组件图库（横图）是同一屏，所以两边都有。
动图比静态稀罕，服务端在结果太少时会放宽横竖限制再捞一批，不会给你一条空页。

## 3. 修「填不满整个 App」

截图里背景只铺了上面一截、下面全黑，原因很具体：`VideoView` 是按**视频自己的宽高比**量尺寸的，
塞进全屏容器就变成上下黑边。现在用 `FillVideoView` 强制按容器尺寸量，`centerCrop` 铺满。

## 4. 切换更快、更稳

- 视频 prepare 之前先异步解第一帧当封面铺上，准备好再淡入播放 —— 不再是黑屏几秒；
- 解不出来/编解码不支持时停在封面，而不是留一块黑；
- 图库动图改下 **720p 样本片**（原片动辄 20~40MB），下载和起播都快一截。
