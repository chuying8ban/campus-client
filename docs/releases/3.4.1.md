# 校园助手 3.4.1

五个反馈一起收：

## 1. 浓淡默认 50%，动图差别更明显

- 换背景（预设 / 照片 / 动图 / 动态）时浓淡自动回到 **50%**；同一类背景之间来回换仍保留你手调的值；
- 动图/视频的浓淡原来只改图层透明度，画面本来就偏暗、底色也暗，50% 和 100% 几乎看不出 ——
  现在**图层透明度 + (1−浓淡) 的底色覆盖**两层一起变，同样一档肉眼立刻能分辨。

## 2. 图库往下翻收起搜索栏

翻到第二行以后搜索框和说明文字自动收起（淡出+上收动画），滑回顶部自动出来。
标题行的「关闭」和「全部 / ▶ 动图」板块切换始终保留 —— 那两样随时要用。

## 3. 子页面按返回键回上一级

图库、预设主题板、动态主题库、课表课程详情、今日日程、权限、反馈、安全、诊断、爬虫、资源浏览这些
子页面都接了系统返回：按返回是**退出一层**，不再直接掉出 App。

## 4. 课表页两个按钮重做

旧的是 Material `TextButton` —— 纯文字、无边界，看着像「两个可点的字」。现在：
- 两颗等宽胶囊（42dp 高、13dp 圆角、间距 10dp）；
- 「更新课表」主操作：紫色→青色渐变底 + ⤾ 图标；「编辑课表」次操作：卡片底 + 描边 + 铅笔图标；
- 往下翻自动收起，给课表腾地方，翻回顶部再出现。

## 验过什么

- 单测全绿（含新增的浓淡默认 50% 三条断言）；
- 修了一条偶发红的老测试（`BoardBackTest` 里手动推进时钟后没开 autoAdvance，全套跑时会抢在 LaunchedEffect 之前断言）；
- 线上包 sha256 回读一致 `2a3682c0…`，7,878,483 字节。

未在真机验：胶囊按钮在你机型上的观感、收起动画的顺滑度。
