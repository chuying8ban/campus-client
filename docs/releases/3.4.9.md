# 校园助手 3.4.9

## 1. 动态主题不再是"一片纯黑"

12 种动效的底色原本是 `#07060C`——在手机上就是纯黑；再叠上 App 的浓淡覆盖（0.75）和上下压暗带，
最后剩下的就是"点了没反应、屏幕变黑"。

- 底色里掺 18% 的主题色，屏幕一眼能看出是紫/蓝而不是黑；
- 每类动效自己的暗色渐变从 60~90% 降到 33~50%，保留区分度但不吃掉光；
- 浓淡覆盖 0.75 → 0.45，上下压暗带 0.06+0.16k / 0.32 降到 0.03+0.10k / 0.21。

12 种动效逐个渲成图验过（`DynPainterLookTest`，平均亮度 26~53/255，最低也没到"黑屏"）。

## 2. 动态主题更跟手

以前每团光（星云 18 团、光斑 26 团）都用渐变 shader **涂满整屏**，一帧二十多次全屏填充，中端机必然卡。
现在只画那个圆本身，填充面积降两个数量级。GIF 主题的解码也从主线程挪到 IO 线程，切换不再顿一下。

## 3. 小组件的图片主题换成真实照片

四张 `widget_art_*` 原来是四条**纯渐变**（用户早先就问过"为什么图片主题还是渐变色"）。
这版换成真照片：**海边 / 红叶 / 夕照 / 神社**，960×420，居中裁切。
亮度从 16~22/255 提到 44~63/255。

## 4. 换小组件主题有回音，坏图不留黑卡

- 应用主题后弹一句「已应用：海边」，不再是"点了没动静"；
- 图片类主题先用当前机器**解一遍**，解不出来就拒绝并提示「这张图读不出来，换一张再试」，
  不会再把设置改成一个解不开的规格（那就是"黑卡"的来源）；
- 保存自己那张图时**回读校验**：`compress` 失败会写出 0 字节文件，以前直接返回 true。
  现在依次用 1200/800/600 宽重试，全失败就返回 false 让界面提示；
- 文件真丢了的话，会依次回落到小组件槽 / App 槽里存的原图，而不是静默退成深色渐变。

## 5. 自检面板能一次问清

`小组件自检` 里新增三颗胶囊：**当前 / 纯色 / 随包图片 / 我的图**，外加一行诊断
（文件在不在、多大、能不能解码、底图中心像素色值）。哪一格是黑的，问题就锁在哪一段。

## 6. 回归测试

- `WidgetThemeCoverageTest`：扫过全部纯色预置、四张图片、每种动效 —— 都要出图、都不能黑成一片；
- `WidgetUserImageTest`：存一张纯红图 → 设成主题 → 底图中心像素必须偏红（证明图真的画进去了）；
- `DynPainterLookTest`：12 种动效逐张渲图 + 亮度断言。
