## 2.3.0 · 小组件重做

上一版交出的小组件在桌面上就是「一块黑 + 三行字」，你截图那块空白占了一半。
这一版把视觉和信息层次一起重做。

### 底
不再是固定纯色 drawable，而是**按主题色现画一张位图**：竖向渐变 + 左上柔光 + 1px 细描边 + 圆角。
- 渐变让卡片有"光从上面来"的立体感，不是贴纸；
- 柔光用主题强调色，换配色时整块底跟着变；
- 描边让卡片从壁纸上立起来（深色底用亮描边，浅色底用暗描边）。

底图按**每个实例的真实格子尺寸**绘制（`getAppWidgetOptions` 的 dp × 密度），拉宽拉高都清晰，
不会像固定图那样被裁掉边。同一尺寸只画一次，有缓存。

### 字
四级层次，桌面 30cm 外也能一眼分开：

- 状态行：色点 + 「正在上课 / 下一节 / 今天 / 已上完」，右端日期与周次
- 课程名：整块唯一的大字（20sp 粗体）
- 时间 · 地点：`10:10–11:45 · 教A301`
- 后几节（最多 3 条）+ 页脚（`还有 1 节` / `点开看完整课表`）

没课时大字是「今天没有课」，下面给一句「好好休息，或者去图书馆坐坐」，
页脚若有未完成任务就写「还有 N 件任务」——不再出现半屏空白。

### 其它
- 拖拽改尺寸会立刻按新尺寸重画（`onAppWidgetOptionsChanged`）。
- 图片主题保留：图片铺满 + 暗蒙版，文字保持亮色。
