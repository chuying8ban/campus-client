# 校园 App 2.1.7

这一版把 App 收回它本来该有的范围：**只服务中国石油大学（北京）克拉玛依校区**。

上一版（2.1.6）把正在试做的「多学校」内容一起打进了正式包：首次安装会先弹一个全国高校目录让你选学校，导入页还摆着安徽理工大学、安徽工业大学、东北农业大学三个"官方登录测试"入口和一个通用课表文件导入。它们都没有真正接入课表读取，出现在正式包里就是错——这一版全部拆掉。

- 首次安装不再要求先选学校：直接就是「导入课表（克拉玛依校区教务）」。
- 「课表 → 更新课表」打开即克校官方教务登录页，没有学校选择对话框、没有外校入口、没有文件导入。
- 删掉随包一起进去的全国高校目录（3000 多所学校列表）与对应的登录诊断/多因子探测代码：正式包里不再有这些页面和上传通道。
- 打包与更新通道也收成一条：不再有"测试版"包名和第二条更新清单，安装包和被检查的清单只此一份。

已装同学：我的 → 检查更新，覆盖安装即可（同一个包名、同一把签名钥匙，本地课表与账号不受影响）。

自动化测试随代码一起调整：只保留适用于克校导入、课表解析、更新校验与界面守则的用例，随本次改动删除的用例都是被删掉页面自己的测试。实际跑数与结果见本文件末尾的实跑记录。
