# 校园助手 3.4.42 —— 圆角为什么"有时"消失

## 根因
不是每次都不圆，是**有条件才不圆**——所以你看到的是"有时"。

3.4.39 我为了让自定义文字颜色看得清，在小组件上加了一层可读性遮罩。那层是用布局里的 `widget_scrim` 做的：一个**铺满卡片的矩形 ImageView**，`setBackgroundColor` 填的是直角矩形。

只要这层显示，它就把底图已经画好的四个透明圆角重新填实 —— 圆角就没了。它只在两个条件同时成立时显示：
1. 你在「小组件」里挑过文字颜色，并且和底板撞色；
2. 当前是图片/动图/视频主题（底板内容不受我们控制）。

所以是"有时"。你的截图正好落在这一档：二次元图主题 + 自定义字色。

另外用像素验过：截图里卡片四角在 (bbox+2px) 处就已经是亮的（157/255），说明那不是某个 20dp 的圆角，而是被一块矩形盖住了。

## 改法
- 新增 `WidgetArt.veil(bitmap, argb, radius)`：把遮罩**画进位图里**，并且按圆角路径 `clipPath` 裁一刀 —— 四角仍然透出去。
- `applyTheme` 里对每一帧（动图/视频）和静态底图都过一遍 `veil`，然后再按透明度 `fade`。
- 布局里那块矩形 `widget_scrim` 现在**永远 GONE**（代码里显式设，注释写明原因，防止以后再被打开）。

## 守这件事的用例
`WidgetCornersTest`（Robolectric `GraphicsMode.NATIVE`，真渲染、真读像素）：
- 圆角位图四角 alpha 必须 = 0，正中必须 = 255；
- 压了遮罩之后四角**仍然** = 0（这条就是这次的 bug）；
- `alpha=0` 的遮罩不许复制位图。

注意：Robolectric 默认的 legacy 图形里 `clipPath` 是空实现，测试会假绿/假红 —— 这个类必须开 `@GraphicsMode(NATIVE)`，已在文件里注明。
