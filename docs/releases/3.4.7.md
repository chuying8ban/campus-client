# 校园助手 3.4.7

## 1. 更新说明弹窗：不再透、不再压字

上一版那张卡是半透明的 —— 主题色板里的 `card` 本身带 alpha（本来要让壁纸透出来），
铺在 Dialog 里就等于把背景一起透，于是底下的课表（"大学英语"、教室、老师）整片压上来。

现在三层结构：

- 整屏压一层深色蒙，挡内容也挡误触；
- 卡片 = 不透明深底 + 主题卡色叠加（`compositeOver`），有主题色相但不透；
- 正文限高自滚，不会再被「知道了」压掉半行。

> 这一条被仓库自己的 `ThemeTokenTest` 拦了一次：`C.line.copy(alpha=…)` 这种写法被禁止，
> 因为那几个令牌自带 alpha，覆盖它会把底变成一块浅灰砖 —— 正是这次"糊"的根因。已改用 `C.lineHi`。

## 2. 静默下载（新功能）

进 App 时在后台查一次清单：有新版本就**直接把包下完、校验完**，全程不弹任何界面。

- 下好了在底部浮一条「新版本已下好 · 点这里安装」，一键拉起系统安装器；
- 同时发一条通知（点开也能装）；
- 「我的 → 自动下载新版本 · 已开/已关」可以关掉，关掉后只剩手动「检查更新」；
- 节流：6 小时内最多试一次；同版本只下一次；已下好的包直接复用；
- 安全边界不变：sha256 + 大小 + 签名三项全过才记「已就绪」，否则整包丢弃。
