# 校园助手 3.1.0

## 1. 修复：换动态主题后小部件打不开

报错是「载入窗口小部件时出现问题」。根因在上一版用的 `AdapterViewFlipper` + `RemoteViewsService`：
这套要求桌面进程去 bind 我们的 Service，MIUI 桌面不做这件事，于是它自己的 RemoteViews 充气失败。

现在改成 **`ViewFlipper` + 12 个现成的 ImageView**：帧由 App 直接写进去，不需要 Service、不需要桌面配合。
12 帧 × 120ms ≈ 1.44 秒一个循环。

## 2. 动态主题升级：让二次元图动起来（动态壁纸那种）

外观 → App 主题 → 选一张图 → **「让它动起来」**：静止 / 微动 / 樱瓣 / 落雪 / 光斑 / 星点 / 萤火 / 气泡。

不是给图加一层粒子就完事 —— 画面本身会**缓慢推近再退**（Ken Burns，幅度 4%），前景再飘一层粒子。
只叠粒子像贴纸在动，只推近又太闷，两个一起才像动态壁纸。

## 3. 桌面小组件也能用同一张会动的图

外观 → 桌面小组件 → 选图 → **「让它动起来」**，同一排选项。
桌面上就是同一套画面（12 帧循环），不占后台、不需要 App 常驻。

## 4. 课和自习结束后自动取消静音

三条保障：
- 静音动作自己带**结束时刻**（含早晚自习，重叠的时段取最晚结束的那个），下课那条闹钟准点恢复
- 恢复的是**你原来的模式**：平时震动就回震动，不再一律变响铃
- 兜底自愈：闹钟被系统清掉 / 手机重启 / 清了后台，App 下次启动或任何一条闹钟醒来时，
  只要发现「还在静音、这一段早该结束」就立刻还回来，并提示一条「已恢复铃声」
