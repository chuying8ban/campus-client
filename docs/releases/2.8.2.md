# 校园助手 2.8.2

## 预设主题：两种款式现在真的分得开

上一版把「浓郁 / 淡雅」合成一块板，但两组的颜色几乎一样（暮紫和雾紫、靛蓝和月蓝、
深海和青瓷 —— 摆在一起分不出）。这次从**两个方向**拉开：

- **浓郁**：饱和、深、光只落在角上，像打了光
- **淡雅**：灰调、亮、几乎无光晕，像一整块雾面纸

板上也分成两段，各带一句说明 —— 不靠眼睛分辨颜色也能选对。

（老 id 没动，之前选过的背景不会失效。）

## 在线图库入口带图了

原来「在线图库」是颗小胶囊，看不出里面有什么。现在是一张卡：上面三条缩略图、下面写
「上千张，可搜 IP」。缩略图从图库里异步取，取不到就留色块 —— 入口不会被网络卡住。

## 搜索加了按钮

搜索框右边一个「搜索」按钮（44dp 高），键盘回车也直接搜。打字仍然等你停 400ms 才发
请求，按钮是明确意图，点了立刻搜，不等。

## 外观页不再挤

- 「自己调颜色」从紧贴色点的小胶囊，改成**整行按钮**，说明文字挪到下一行
- 「在线图库」和「用自己的照片」改成两张**等宽卡片**并排，各带一条缩略区
- 「换回内置背景」从两个按钮中间挤着的文字，挪到卡片下方单独一行

## 顺手修的

图库缩略图下载加了一条退路：原来只走 App 那条自选链，某些网络下会整片空白，现在失败
会退回普通 HTTP 连接再试一次。
