# 校园助手 3.4.15

## 动图库「搜不到动图」

接口本身是好的（同一时刻 `anim=1` 返回 57 条 landscape）。问题在我们这边的第二道闸：
`items.filter { it.ofOrient(orientKey) }` —— 只要方向字段对不上，整批就被滤成空，
界面只剩下「没有动图了」，看着像图库空了。

现在：**只要接口给了数据就一定显示**。方向对不上时先全部显示，并在上面写清楚
「接口返回 N 条，但方向标记对不上（…）—— 已先全部显示」，把真实原因摆出来。

## 小组件用动图抽帧全黑

`WidgetFrames` 原来固定抽 0 / 0.32 / 0.64 / 0.96 秒四帧。动图开头常是淡入黑场，
四帧全黑 → 桌面小组件看着就是"没有主题"。改成按**整段时长**的 12%~84% 均匀取帧，
每一帧都落在正片里。

## 设了不生效也不说

从图库给小组件设动图，现在会先试着抽一遍帧：抽不出来就**退回原来的主题**并提示，
不再"设置成功但桌面没反应"。
