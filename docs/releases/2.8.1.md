# 校园助手 2.8.1

## 外观：预览删了，改成真预览

「App 主题」里原来那块手机样式的预览框已经删掉 —— 改主题本来当场就落到当前这一页上，
再摆一个"看起来像真机"的框，反而让人分不清哪个才是真的。现在调明暗、强调色、背景，
眼睛看到的就是结果。

## 页面背景 →「预设主题」

原来 12 个色板分成「浓郁 / 淡雅」两节平铺，占掉大半屏。现在：

- 外面只留**一块卡片**：左边是当前背景的缩影，右边写着「当前：暮紫 · 12 款可选」
- 点进去是独立的**预设主题**板，12 款合成一板挑（不再分浓郁/淡雅）
- 点一下就换、不关页，方便来回比

「在线图库」和「用自己的照片」还在外面，选完照样能调「图片浓淡」。

## 图库：加了 IP，也加了热门词

之前搜索只认题材词，IP 名（原神、崩铁…）查不到东西，所以显得"内容贫乏"。现在服务端
补了 IP → 英文标签的映射，并且先用上游的否定标签（`-simple_background`）把白底/纯色
底的图排掉，可用结果明显变多：

- 原神、崩铁/星穹铁道、绝区零、鸣潮、明日方舟、蔚蓝档案、碧蓝航线、少女前线、妮姬、
  第五人格、英雄联盟、永劫无间、初音未来、FGO/Fate、LoveLive、偶像大师
- 动画：鬼灭之刃、咒术回战、间谍过家家、芙莉莲、孤独摇滚、莉可丽丝、紫罗兰永恒花园、
  新世纪福音战士、刀剑神域、进击的巨人

搜索框下面加了一排**热门词**（原神 / 少女 / 樱花 / 校服 / 星空 / 赛博 / 和服 / 猫），
点一下就等于搜一次 —— 空着进来也能立刻看到图。

没收录的中文词不再给一页空白，会直接提示「这个词还没收录，试试 IP 名或题材」。
