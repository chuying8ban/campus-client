## 2.2.2 · 勿扰访问能授权了

### 根因
「自动静音」一直显示"缺：勿扰访问"，点「去授权」跳过去的「模式访问权限」列表里**没有校园助手**。

原因不在提示逻辑：系统只把**清单里声明了 `BIND_NOTIFICATION_POLICY_ACCESS_SERVICE` 服务**的应用
列进那份名单。之前只声明了权限、没声明服务，所以列表里永远找不到本应用 → 授权永远授不上 →
自动静音永远不生效。

这一版补上：
- `android.permission.ACCESS_NOTIFICATION_POLICY` 权限；
- `alarm.PolicyAccessService`（导出、绑定权限正确），它不执行任何逻辑，只为"出现在名单里"。

现在进「我的 → 自动静音 → 自检 → 勿扰访问 → 去授权」，列表里能看到校园助手，打开后
「静音不会生效，缺：勿扰访问」这行会消失。

### 小组件邀请卡挪到最上面
上一版把邀请卡放在今天页最底部，要滚到底才看得见 —— 等于没有。现在它出现在
**核对细带下面、第一屏就可见**（只有桌面上还没有小组件时才出现）；
已经加过的，页尾只留一句"桌面上的今日课表已有 N 个 · 换配色"。

### 说明
勿扰访问是系统级授权，只在这台手机上生效，App 不会拿它做别的事：只在课程开始/结束时把
铃声模式切一下，下课后恢复。
