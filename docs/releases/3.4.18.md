# 校园助手 3.4.18

## 「图片主题也只显示为黑色」

你那屏自检其实已经把答案写出来了：`我的图 55KB 1200×675 · 中心像素 #ff010c29 · 平均亮度 20/255`。
20/255 就是"看着像黑"的亮度 —— 这张图是从一段暗色动图里抽的帧，铺到小组件上跟纯黑没区别。
所以不是渲染没生效，是**图本身太暗**。

两层都修：

1. **素材端**：`ImgLift` —— 平均亮度低于 50 的图自动抬到 ~95（最多 3 倍），落盘前做一次；
   已经存过的老图在绘制时也会抬（不用重新选）。
2. **底图预算**：`BG_MAX_PX` 120k → 60k（≈240KB）。120k 像素的 ARGB 是 480KB，
   加上别的一起逼近 binder 的 ~1MB，MIUI 会**静默整块丢**，桌面只剩黑底文字。

自检多一行「走轮播：4 帧 · 宽×高」或「走静态底图：宽×高 ≈ XKB」—— 这两条分支完全不同的排查路径，
以后不用猜。
