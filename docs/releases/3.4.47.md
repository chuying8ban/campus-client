# 校园助手 3.4.47 —— 字体（App 与小组件分开）

## 在哪儿改
- App 字体：外观 → App 主题 → 字体
- 小组件字体：外观 → 桌面小组件 → 字体

两处各存各的偏好（`app_font` / `widget_font`），改一边绝不动另一边 —— 有测试守着这条。

## 三种字体
默认（无衬线）/ 等宽 / 衬线。用的是系统自带通用族，不打包第三方字体：
不涉及授权问题、体积不变，中文也会跟着系统字体走，不会出现"英文好看、中文缺字"。

## 为什么小组件要"三份布局"
`RemoteViews` 只允许白名单方法，`setTypeface` 不在里面（要传 Typeface 对象，跨进程传不过去）。
字体只能在**桌面充气我们布局的那一刻**由 `android:fontFamily` 定下来 —— 所以一种字体 = 一份布局。
三份 XML 的唯一差异就是那 9 行 `android:fontFamily`（有测试逐行比对，防止以后改一处忘两处）。

## 刻意不动的两处
- **时间/数字仍然等宽**（`Digits`）：并排的数字要是不等宽，时间会"跳字"，这是排版底线；
- **App 内所有排版样式一起换**（标题/正文/标签全部铺上），不会出现"有的地方换了有的没换"。
