# 校园助手 3.4.29

这一版把你点名要的七件事一起做完了，逐条对账：

## 动图到底还能继续加载
服务端 `anim=1` 那条以前固定只抓上游第 1~3 页、按 score 取前 100、`has_more` **恒为 false** —— 所以永远只有 13 张精选、永远显示「已经到底了」。现在按 page 真翻（第 N 页 = 上游 `(N-1)*3+1 ~ N*3`），`has_more` 按实际抓到的条数判断。13 张只是**第一页**。

## 排序：时间 / 热门 / 评分
- **时间**（默认）：上游 `id` 倒序，就是最新；
- **热门**：`score` 降序（总赞数）；
- **评分**：`score ÷ 发布天数`（点赞密度）—— 纯按 score 排，前三页永远被几年前的老图占着，按天折算才是"这张到底受不受欢迎"。

三种都是服务端现算（safebooru 对 `order:score` 会 500，所以不用它的排序参数），换排序会重新搜、缓存分桶。

## 三支缓动的动态主题
新增 **绫罗**（丝带一样慢慢流）、**暮色**（天边呼吸）、**涟漪**（一圈圈推开）。周期 20~40 秒、只用柔光、没有硬边和闪烁 —— 参照的是动态壁纸那种"整屏在呼吸"，不是往画面上撒东西。App 主题和小组件共用同一支画笔（`DynPainter`），所以两边看起来是同一套。

## 小组件播放速度
慢 / 稍慢 / 正常 / 稍快 / 快。改的是**时间轴走多快**（帧按墙钟挑），不是简单抽帧；缓存键带上速度，改完立刻重做帧。

## 文字颜色
预览下面一排色点（默认/白/暖白/淡紫/淡蓝/淡粉/暖黄/淡绿），**App 正文和小组件文字同一支**。实现上只动文字令牌（`C.txt/txt2/txt3` 按层级往底色退），底色和强调色不跟着变。

## 下载进度
- 图库格子上：转圈下面直接写 `45%`（服务器给了 Content-Length 才算百分比，没给就显示已下载多少 MB）；
- 离开图库：App 顶部一条「正在下载素材 · 45%」，协程跑在页面之外，切页/回桌面都不中断；状态栏也有常驻通知。

## 静默更新弹窗 + 防断
后台下好后弹一次「新版本已在后台下好」（按 versionCode 去重，不重复骚扰），点「立即安装」或「稍后」。断点续传本来就有（`.part` + Range 续传 + 重试），这次没有改动这块逻辑。

## 小组件圆角
按短边 20%、最低 22dp → **短边 12%、夹 12~24dp**。不是直角，也不再是半个胶囊。

## 公告通道（新）
