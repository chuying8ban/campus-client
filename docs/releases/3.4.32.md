# 校园助手 3.4.32

## 排序是空壳 —— 根因在服务端
点「时间/热门/评分」不换顺序，是因为每一页只凑到 **13 张**（横竖过滤把 80% 都筛掉了），三种顺序在一屏里看不出差别；而且 `has_more` 用「过滤后还剩几条」判断，13 < 50 就恒为 false —— 所以永远「已经到底了」。

现在改成**动图池**：按横/竖并行抓上游多页（每页 100），过滤后去重，池子按 orient 缓存 5 分钟；排序在**整个池子**上做，再按页切片：
- 时间 = 上游 id 倒序（显式排序，池子是并行抓的，不排的话每次顺序会变）；
- 热门 = score；
- 评分 = score ÷ 发布天数。

实测：池子 81 → 172 → 296 张，第 1/2/3 页 id 各不相同，三种排序首图不同，`has_more` 为 true。

## 不再有「精选」
按你说的：加载多少显示多少，往下拉就继续加载。文案里的「精选」两个字删了，一页 30 张（以前 100 张一次拉，等得久还看不出翻页）。

## 文字颜色：位置对了，颜色也补齐了
上一版这个控件只挂在「桌面小组件」那一页，而你在「App 主题」页找 —— 所以「没有出现」。现在是**同一个控件摆两处、只有一份设置**，改哪边都整机一致；颜色里加了**黑、深灰**，连同白/暖白/淡紫/淡蓝/淡粉/暖黄/淡绿。

## 换主题立刻生效
以前只写了偏好就走人，桌面要等 refresh 的第二次渲染（旧帧 → 预热新帧 → 再渲染），所以「过了一会才出现」。现在选主题走 `applyNow`：写偏好 + 清掉旧帧缓存 + 立刻重画，一步到位。另外从图库选完主题回到主题页，会自己重读一次真实状态。
