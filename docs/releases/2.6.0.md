## 2.6.0 · App 背景图库 + 小组件全机型适配

### ① App 外观也有图库了
外观 → App 主题 → 页面背景 → **在线图库**（在「用自己的照片」旁边）。
点一张就下载存本机，和相册选图走同一条落盘逻辑（照样量明暗极值、照样自动配遮罩）。

现在有两套图，各自对应用途：
- **摄影**（10 张）：夜空、日本街道、银河、秋叶、富士山… 给 App 页面背景；
- **插画**（13 张）：之前那批二次元插画，给桌面小组件。

### ② 真的连了免费在线图库
服务端 `tools/art_sync.py` 从 **Openverse**（openverse.org，聚合 CC 授权作品、无需 API key）拉图，
只收 CC0 / 公共领域 / CC BY / CC BY-SA，下载后统一压到 1280 宽，连同**作者、协议、原页面**一起写进清单。

同步时做了两道质量闸：
- 近白像素 > 55% 或颜色标准差 < 12 的一律丢弃（这类就是白底剪贴画/素材图，铺满屏幕一片白）；
- 只收横图（1.2~2.4 比例），App 背景和小组件都是横的。

App 只连我们自己的域名（校园网/移动网都能过），第三方挂了我们不受影响；
图库里显示的"作者 · 协议"就是 CC 协议要求的署名。

### ③ 小组件适配所有机型
不同 ROM 给的格子尺寸差很多（MIUI 4×2≈155dp、原生≈170dp、2×2 只有 110dp），所以现在是**宽高各自分档**：
- 高度：≥175dp 三行 / ≥145dp 两行 / ≥118dp 一行 / 更矮只留状态+课名（不再留半行被裁的字）；
- 宽度：< 230dp 去掉周次、< 195dp 再去掉日期、< 210dp 整体降一档字号并收边距；
- 每个实例单独兜底：某个实例画挂了只记日志，不连累桌面上其它实例。

分档逻辑抽成纯函数 `rowsFor()/isNarrow()`，由 `WidgetAdaptiveTest` 钉住。
