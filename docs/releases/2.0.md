# 校园助手 2.0 更新说明

## 本次变化
- 教务课表改为在学校官方 HTTPS 页面登录后导入。App 不读取、不保存教务密码，不向自有服务器上传教务密码或 Cookie。
- 课表默认保存在本机；云端同步需先阅读条款并明确同意。
- 「安全与隐私」统一说明上传范围、后台可见范围、设备身份与恢复限制。
- 登录令牌在本机加密保存，加密失败不回退明文。
- 读取失败保留当前教务页面，可刷新后重试。
- 返回退出前显示确认；子页面优先正常返回。

## 使用提醒
- 本项目不是学校官方 App。选课监控仅提供余量信息与提醒，不代选、不保证结果。
- 教务网页在手机和桌面模式下仍可能显示过小、横向截断或存在空白；可尝试缩放。此次不宣称已解决网页排版。
- 不再提供由自有服务器保存教务密码并代读课表的方式；课表有变化时请重新从官方页面导入。
- 新建云端身份为随机访客账号，约 30 天过期；卸载或清除数据后不支持跨设备恢复。仅本机使用不需要云端同步。
- 正式版可覆盖旧正式版，保留本机数据。独立隐私测试版与正式版数据互不相通，测试版数据不会自动搬入正式版。

## 安装
Android 8.0 及以上，下载 APK 后按系统提示安装；旧正式版直接覆盖，不要先卸载。
