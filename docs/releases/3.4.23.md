# 校园助手 3.4.23

## 「更新时不能使用 App」

截图里那个"正在下载更新 · 7%"的框，是**全屏遮罩 + 居中卡片**：盖住整屏、吃掉所有触摸。
7.9MB 在校园网要几十秒，这几十秒里 App 等于锁死 —— 正是要免掉的东西。

改法：下载中的状态**不再走全屏浮层**，改成底部一条细条：

- 不铺遮罩、不拦截触摸 —— 课表、图库、设置照常点；
- 显示「正在后台下载 3.4.23 · 42%」+ 进度条；
- 有个「隐藏」：只收起这条，**下载不会中断**（协程活在 CampusShell 的 scope 里）；
- 断网重试时文案变成「网络断了，正在接着下」，不假装在走。

下载完成仍然是原来的安装提示（那一步必须点，系统安装器要人来确认）。
