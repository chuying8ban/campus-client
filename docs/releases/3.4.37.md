# 校园助手 3.4.37 —— 闪退与"能看见的崩溃"

## 做了什么
1. **列表去重**：网格用 `id` 当 key，同一条出现两次会抛 "Key was already used" 直接崩。现在渲染前先按 id 去重。
2. **自动加载加闸**：只有你**真的滑动过一次**才会触发"滑到底加载更多"。图片没解码出来时网格条目很少，判"到底"会一直成立 → 连发请求、列表无限增长，内存直接顶爆。
3. **崩溃上报**：装了未捕获异常钩子，崩之前把堆栈 POST 到自己的服务器（只发版本号/机型/堆栈，不发任何用户数据），落 `/var/lib/artapi/crashes.log`。

## 为什么先发这个而不是直接修好
按你说的"一打开就闪退"，说明崩在打开那一刻 —— 我这边没有真机（`adb devices` 为空），只能靠代码推断。与其一次一次猜，不如让崩溃自己说话：这一版装上后再崩，我 ssh 上去就能看到具体是哪一行、什么异常，下一次改动才有依据。
