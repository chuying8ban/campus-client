# 校园助手 3.4.17

## 终于抓到「小组件换主题没反应」的真凶

自检里终于把原始异常打出来了：

```
android.widget.RemoteViews$ActionException:
view: android.widget.ViewFlipper can't use method with RemoteViews: setAutoStart(boolean)
```

`ViewFlipper.setAutoStart()` 和 `setFlipInterval()` **不是** `@RemotableViewMethod`。
RemoteViews 是在**桌面进程**里执行这份指令集的，跑到这一句直接抛异常 —— 于是
**整份** RemoteViews（底色、文字、底图、帧）全都没落地。所以不管换什么主题，
桌面那张卡都停在旧样子。之前一直在查位图预算、帧数、launcher 丢图，方向全偏了。

## 修法

- 删掉 `setAutoStart` / `setFlipInterval`；
- 改用 `ViewAnimator.setDisplayedChild(int)`（这个是允许的），按时间挑一帧；
- 外再包 `runCatching`：以后再有类似调用，也不会把整份更新带走。

## 桌面动效的现实

桌面自己不会翻页 —— 真要 4 帧轮播，只能靠反复 `updateAppWidget`（每 1.3 秒一次），
那是电池自杀。所以现在的策略是：**每次刷新/重绘换一帧**，卡片是"会变"的，
但不是"一直在动"的那 4fps。要真动效得单独做前台定时刷新，等他点头再说。
