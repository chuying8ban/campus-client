# 校园助手 3.2.0

## 1. 修复：换动态主题后小部件打不开

桌面报「载入窗口小部件时出现问题」。根因是上一版用的 `AdapterViewFlipper` + `RemoteViewsService`：
这套要桌面进程 bind 我们的 Service，MIUI 桌面不做，于是整张卡充气失败。

改成 **`ViewFlipper` + 12 个现成 ImageView**：帧由 App 直接写进去，不需要 Service、不需要桌面配合。

## 2. 动态主题升级：让二次元图动起来（动态壁纸那种）

外观 → App 主题 → 选图 → **「让它动起来」**：静止 / 微动 / 樱瓣 / 落雪 / 光斑 / 星点 / 萤火 / 气泡。

画面自己**缓慢推近再退**（4% 幅度），前景再飘一层粒子。只叠粒子像贴纸在动，只推近又太闷，两个一起才像壁纸。

## 3. 新增：上传自己的动图 / 视频当背景

外观 → App 主题 → **上传动图 / 视频**：gif、mp4、webm（80MB 以内）。
- gif 用系统 `AnimatedImageDrawable` 自己循环，不耗 CPU 自己画；
- 视频用 `VideoView` **静音循环**播放，不抢音频焦点；
- 走 `OpenDocument`，**不申请存储权限**，文件只存在本机 `files/appearance/`，不上传。

## 4. 桌面小组件也能用你传的动图 / 视频

外观 → 桌面小组件 → 点「用你传的 GIF/视频当背景」。
桌面放不了视频，就**抽 12 帧**轮播（视频取 0~1.4 秒的 12 个时间点，gif 按时长均分），不占后台。

## 5. 课和早晚自习结束后自动取消静音

- 静音动作自带**结束时刻**（重叠时段取最晚），下课闹钟准点恢复；
- 恢复的是**你原来的模式**：平时震动回震动，不再一律变响铃；
- 兜底自愈：闹钟被系统清掉 / 重启 / 清后台，App 下次起来发现「还在静音、早该结束」就立刻还回来，并提示「已恢复铃声」。

## 6. 每次更新后弹一条更新说明

更新完第一次打开，通知栏会有一条「校园助手已更新到 x.y.z」，正文就是这一版改了什么
（随包发布的 `assets/changelog.tsv`，同一版只弹一次，不堆通知）。
