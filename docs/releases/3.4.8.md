# 校园助手 3.4.8

## 1. 图库搜索框：文字不再叠成一团

截图里搜索框内两行字压在一起，还有一个「搜索」按钮压着输入区。

真因是 `AnimatedVisibility` 的内容**不是 Column**：它按 Box 语义把多个子项摆在同一位置。
上一版把"搜索行"和"▶ 动 = …说明"并列放进去，两句字就叠在一起了。这版把它们包进 `Column`。

## 2. 下滑收起范围扩大

你说"下滑隐藏搜索栏和标签栏"：现在热门标签那一排也跟着收，只留标题、「关闭」和「全部/动图」板块切换。

## 3. 小组件：换主题没反应的两条兜底

- 自检面板里那张底图也是黑的 ⇒ 不是桌面丢图，是我们这条链路自己的问题。这版查了「我的图」这条路：
  文件可能被清理工具删掉、也可能当初压缩失败，以前这种情况会**静默退成深色渐变**（看着就是"纯黑、没换"）。
  现在会依次回落到小组件槽 / App 槽里存的原图，只要有一份能解码就用；
- 自检面板新增三颗胶囊：**当前 / 纯色 / 随包图片 / 我的图**，点一下就用那个规格重画，
  外加一行诊断（文件在不在、多大、能不能解码、底图中心像素色值）。
  点这三颗，哪一格是黑的，问题就锁在哪一段。
