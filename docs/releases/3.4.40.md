# 校园助手 3.4.40

## 为什么两条路会打架
之前是两条独立路径：进 App 自动在后台下一份，你点「检查更新」又下一份。两条都往 `filesDir/update/` 写同一个文件，互相清对方的半包 —— 表现就是"更新总是失败、进度还倒退"。加租约（`UpdateLease`）只是让它们排队，根子还在：**同一件事有两个入口**。

## 现在的做法：只留一条
- 删掉 `SilentUpdate`（静默下载整套：启动时查清单、后台下完、底部"新版本已下好"浮条、"已在后台下好"弹窗）；
- 删掉「我的 → 自动下载新版本·已开/已关」这个开关；
- 删掉对应的单元测试；
- 旧版本静默下载留下的残包 + `ready_path/ready_code/auto_download` 记账键，在新版第一次启动时自动清掉（`UpdatePrefs.purgeSilentArtifacts`）。半包和续传数据不动 —— 手动下载还要接着用。

更新入口现在只有：「我的 → 检查更新」（进 App 时那次自动检查还在，但它只查清单、弹提示，不下载任何字节）。

## 「隐藏」按钮
下载进度条上那个「隐藏」去掉了。它和静默那条路一起制造了"到底谁在下载"的混乱；现在条子本来就贴在底部、不挡操作，不需要再收起来。说明文案同步改成「可以继续用 App；这条条不挡操作，下好会再提示」。

单测 `UpdatePanelTest` 里那条旧用例改成守新契约：下载条上**不许再出现「隐藏」**。

线上 sha256 见 release 页。
