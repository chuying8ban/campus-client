## 2.3.2 · 小组件「载入失败」修复

### 现象
桌面那块显示「载入窗口小部件时出现问题」。

### 根因
RemoteViews 只允许**带 `@RemoteView` 注解**的控件，而小组件布局里用了两个不在名单里的：

- `android.widget.Space`（当占位/推挤用的）
- 裸 `<View>`（蒙版、分隔线、圆点、弹簧位）

launcher 充气到这些标签时直接抛 `InflateException: Class not allowed to be inflated`，
桌面就显示那行错误。

这其实也是之前"桌面上有实例但一片空白"的真凶 —— 从 2.2.0 加图片主题那时起，
布局里就有了裸 `<View>`，只是每次表现不同。

### 改法
- 所有占位/分隔/蒙版改成 `ImageView`（它在白名单里，`android:src` 留空即可）；
- 状态圆点用 `ImageView` + shape drawable；
- 新增 `WidgetRemoteViewsInflateTest`：在单测里真的把布局塞进 `RemoteViews.apply()` 充气一次，
  以后谁再往布局里塞白名单外的控件，发版前就红。
