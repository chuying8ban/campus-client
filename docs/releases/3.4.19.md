# 校园助手 3.4.19

## 「这一块的功能指向不明」

三处都在说同一件事：**界面上放了一堆控件，但没写它们管什么。**

1. 「用你传的视频当背景」是一颗孤零零的胶囊 —— 看着像标签，其实点了会切主题。
   现在归到「我传的素材」小标题下，文案改成动作句：「点这里，把视频用到桌面这张卡」，
   正在用时显示「✓ 桌面正在用你传的视频」。
2. 「动效」那一排原来固定写「桌面上这张卡片会自己动……4 帧循环」—— 这句是**假的**：
   桌面不会自己翻页（`ViewFlipper.setAutoStart` 根本不能走 RemoteViews，3.4.17 才因此修完）。
   现在文案跟着选择变：静止时说「现在是静止的…不动的时候最省电」；选了某种动效时说
   「『樱瓣』花瓣从画面前面飘过。桌面不会连续播放（系统限制），每次刷新换一帧」。
3. 标题从「让它动起来」改成「动效（作用在你选中的那张图上）」，指代明确。
