# 校园助手 3.4.24

## 「没有实现圆角，外边有黑色的矩形」

圆角是**画在位图里的**：`WidgetArt.roundedWithScrim` 用 `drawRoundRect` 铺 BitmapShader，
四个角以外的像素是透明的。问题出在底下那一层：

```kotlin
rv.setInt(R.id.widget_root, "setBackgroundColor", opaque(theme.bgColor))
```

这层不透明底色原本是"万一 launcher 丢位图，至少还是张深色卡"的保底 —— 但它
**正好把位图的透明圆角填成了黑色直角**。所以看上去就是"圆角图 + 外面一圈黑方框"。

改成根容器透明（`Color.TRANSPARENT`）。只有连位图都画不出来时，才退回不透明底色。
