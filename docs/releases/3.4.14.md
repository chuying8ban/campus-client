# 校园助手 3.4.14

## 「小组件自检」一直是个假现场

自检预览直接调了 `themeViews()` —— 那条路**只贴主题、不填文字**。所以在自检里永远看到
一个没有文字的黑框，用户据此判断"小组件没有主题"，其实自检本身就不代表桌面。

现在把绘制拆成 `views()`（算尺寸）→ `viewsSized()`（真正画），自检和桌面走**同一条**
`viewsSized`，并且用**真实课表数据**构建 model。自检里看到的就是桌面上的样子。

自检里还多了两行硬信息：

- **桌面实例** `#id 宽度×高度dp`，或者「桌面上还没有这个小组件」—— 先排除"根本没加"；
- **底图平均亮度 X/255**，低于 12 直接标「几乎全黑」—— 这就是"看着没主题"的另一种真相。

## 动图/视频当小组件图，封面是黑的

`stillBitmap()` 原来取 `getFrameAtTime(0)`。很多动图第一帧就是淡入的黑场，
于是"我的图"存下来是一张纯黑图（用户那台机器实测中心像素 `#010312`）。
改成取 8% / 25% / 45% / 65% / 85% 五个时间点，**挑平均亮度最高的一帧**当封面。

## 图库动图空白

同一时刻服务端 `anim=1` 有 57 条，用户那张截图却是空的 —— 多半是那次请求没回来。
空白页现在给一颗「重新读一次动图」按钮，不用退出重进。
