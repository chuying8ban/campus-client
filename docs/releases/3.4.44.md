# 校园助手 3.4.44 —— 高画质帧的授权补丁

## 上一版可能翻车的点
3.4.43 把动态帧从"位图塞进 binder"改成"给桌面一个 `content://` URI，桌面自己去读文件"。画质上去了（300 多像素宽 → 960 像素宽），但有个真实风险：

`setImageViewUri` 的 URI 是**桌面进程**去读的，而桌面对我们的 `FileProvider` 本来没有任何权限。多数 ROM 的系统服务会替我们转授读权限，但不是所有版本、所有桌面都这么做（MIUI 尤其不保证）——网上有一堆人踩这个坑：URI 设进去了，桌面显示空白。

## 这一版补的
- 遍历所有桌面应用（`ACTION_MAIN` + `CATEGORY_HOME`），对每一份帧文件的 URI 主动 `grantUriPermission(..., FLAG_GRANT_READ_URI_PERMISSION)`；
- 底下那张静态底图保留 —— 万一还是读不到，你看到的是"清晰但不动的图"，不是空白卡；
- 遮罩与透明度路径不变。

## 现在三种可能的表现，请照实告诉我
1. 动起来 + 清晰 → 成了；
2. **不动但清晰** → URI 被拒了，退回了静态底图，我换一条路（比如少帧换更大像素：2 帧、每帧更大）；
3. 空白/只剩文字 → 更糟，先在外观页把「动态主题画质」切到「省内存」，我按这个方向重做。

线上 sha256 见 release 页。
