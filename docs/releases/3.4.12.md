# 校园助手 3.4.12

## 动图主题整屏发黑

选了一段图库动图当 App 背景，退出后整页黑、只剩左边一条。三层原因叠在一起：

1. **压暗过头**：媒体图层 alpha 只有 0.5（浓淡 50%），上面又压 `(1-k)*0.75` 的底色、
   再加一条最厚 0.72 的上下压暗带。一段本来就偏暗的片段，三层叠完就是纯黑。
   → 图层 alpha 抬到 `0.55 + 0.45k`，底色覆盖降到 0.45，压暗带最厚 0.42（和动效那边同一套数字）。
2. **下载可能不完整**：图库那段视频是流式下载，断了也会落盘成一个"有大小、放不了"的 mp4。
   这种文件 VideoView 不出画面、抽封面也失败 —— 整层只剩底色。
   → 落盘后立刻用 `MediaMetadataRetriever` 验时长和宽高，验不过就删掉并提示「这段动图没下完整，再点一次试试」。
3. **坏了不会自愈**：背景还指着那个坏文件，下次进来继续黑。
   → 进 App 时检查一次当前媒体背景，放不出来就删文件、退回「暮紫」预设。
