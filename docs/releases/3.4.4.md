# 校园助手 3.4.4

## 1. App 内弹「这一版改了什么」

以前只有一条系统通知：会被划掉、被勿扰吞掉、被"清理"一波带走，装完新版根本不知道改了什么。

现在装完新版第一次进 App，直接弹一张卡片：标题「已更新到 x.y.z」+ 逐条改动，点「知道了」才收起。
数据仍然是随包的 `assets/changelog.tsv`（装的是哪版就说哪版，不走网络）。

已读标记和系统通知**分开记**（`seen_in_app`），谁先谁后都不影响另一边。

## 2. 桌面小组件页：「在线图库」挪到最上面

原来在线图库是页面下方一行小字按钮，翻半天才看到。现在它和「动态主题库」并排放在页首：

- **在线图库** · 上千张横版画，含 ▶ 动图
- **动态主题库** · 72 款会动的小组件背景

下面那行重复的入口同时删掉 —— 同一件事不留第二个入口。
