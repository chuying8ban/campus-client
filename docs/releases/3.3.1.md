# 校园助手 3.3.1

## 1. 修「载入窗口小部件时出现问题」

动态主题的小组件要一次把整组帧塞给桌面。3.3.0 是 12 帧、每帧按卡片尺寸的 0.7 倍画，
加起来几十 MB —— 既可能把 provider 撑爆，也超过桌面愿意接收的量，于是整块报错。

- 帧数 12 → **6**（240ms 一帧，同样是慢镜头观感），每帧像素压到 17 万以内，全组 ≤ 4MB；
- 抽帧时的原始帧算完立刻回收，内存缓存从 4 份降到 1 份；
- 桌面只收到实际存在的帧，多出来的 ImageView 直接隐藏。

## 2. 修「小部件的视频变成主题的了」

根因是 **App 背景和桌面小组件共用同一份媒体文件**：给小组件换一个视频，App 的背景也被换掉，
小组件再读到的其实是 App 那份，看起来就是"串了"。

- 媒体分槽：`theme_media_app.*` / `theme_media_widget.*`，互不覆盖（旧文件自动认作 App 的）；
- 图库里给小组件选动态图只写小组件槽。

## 3. 换动图更快 + 等得到

- 帧生成结果**落盘缓存**（PNG，带透明圆角），桌面刷新、进程被系统杀掉重建都不用重画；
- 换主题时先在后台把帧备好再通知桌面刷新，回桌面基本是"已经是新的"；
- 图库点动态图时显示「正在下载这段动图…选中的是高画质原片，请耐心等几秒」，顶部说明也点明了比静态慢。

## 验过什么

- 单测 737 条全绿，新增：帧总量 ≤ 8MB 的硬预算、帧落盘缓存、两个媒体槽互不覆盖；
- 线上包 sha256 回读一致 `efe82474…`，7,878,115 字节。

真机未验（手上没有设备直连）：6 帧在 MIUI 上的动感是否够顺、动态原片下载的实际耗时。
