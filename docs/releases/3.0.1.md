# 校园助手 3.0.1

## 修复：桌面小部件默认圆角

你截图里那块卡片四角是直角 —— 原因是**图片主题**走的是"把照片缩放到卡片大小"这条路，
拿到的一张完整矩形位图，直接塞进了桌面的 ImageView。

桌面小组件(RemoteViews)里没有 `clipToOutline`、没有 `ShapeableImageView`，也没有任何
"圆角"属性：圆角只能**画进位图里**，让四角变成透明像素。这次补上 `WidgetArt.rounded()`：

- 图片主题：缩放铺满后再裁圆角
- 动态主题：每一帧渲染完同样裁圆角（圆角按整卡计算再按 60% 缩放，和静态主题一致）
- 纯色/DIY 主题：本来就是画的圆角，不变

半径仍按短边 20%、夹 22~46dp；新增 4 条单测直接读像素验证"角上透明、中间保色"。
