# 校园助手 3.4.31 —— 真 60 帧：动态壁纸

## 先说结论
**桌面小组件做不到 60 帧，这不是没优化，是框架里没有这条路。**

小组件的每一帧，都要把一张位图跨进程（binder，单次约 1MB 上限）交给桌面进程，再由桌面自己重绘；桌面还会对高频 `updateAppWidget` 节流。我们之前是 4 帧、按墙钟挑帧，看起来就是"几乎不动"。把推送频率硬拉到 60 次/秒只会：位图被丢、桌面降频、耗电飙升，观感也不会到 60。

## 真 60 帧的解法：动态壁纸
这一版在「外观 → 桌面小组件主题」里加了一个入口：**设为动态壁纸 · 真 60 帧**。

- 用的是**同一支画笔、同一套主题**（你在小组件主题里选的那一支，含播放速度和浓淡）；
- 真 60 帧：自己拿 Surface，16ms 一帧，直接画；
- 桌面滑动、打开 App 都在它上面，视觉上就是整屏在呼吸的动态壁纸；
- 点进去是系统壁纸确认页 —— 换壁纸必须用户自己确认，应用不能静默换（Android 的规矩）。

## 小组件这边
小组件保持原来的行为：跟随课表、跟随主题、点一下能刷新。它负责"一抬眼看到今天的课"，动态氛围交给壁纸。
