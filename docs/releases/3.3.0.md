# 校园助手 3.3.0

## 1. 外观页不再堆主题

之前「动态主题」四张卡 + 「动态主题库」一整行直接铺在 App 主题页，把真正要用的东西挤下去了。现在：

- 粒子类动效（极光/星轨/呼吸/落樱…）**并进「预设主题」**，和其它配色在同一个板里，缩略图是真在动的；
- 预设板顶部是「动态」，下面是原来的配色板，入口卡片的副标题改成"N 款配色 + 动态"；
- 「更多动态」还留在预设板里（72 款可搜），不再占首页位置。

## 2. 在线图库：静态 + 动态合并

图库搜索结果里现在**混着动态内容**（safebooru 的 `animated` 投稿，mp4/webm）：
- 每 4 张静态插 1 张动态，静态不足一屏时动态补在后面；
- 动态卡右上角有 **「▶ 动」** 角标，顶部有一行说明；
- 点一张动态图 = **下载整段视频**存为动态壁纸（不是解码某一帧）：
  - App 背景：直接当动态壁纸循环播放（静音）；
  - 桌面小组件：抽 12 帧轮播。

## 3. 服务端

`/api/art/search` 现在同时返回两类内容（`animated: true` 标记），`/api/art/img` 会按扩展名回
`video/mp4`、`video/webm`，手机端不用直连境外图床。素材量：safebooru 静态百万级 + 动态投稿数万级，
搜什么词都够翻。

## 验过什么

- 线上接口实测：搜「樱花」（横图）返回 21 条，其中 7 条动态；`/api/art/img` 回 `video/mp4`，1.7MB 真视频；
- 单测新增：mp4 字节能落盘成视频主题、非视频字节拒绝、换新清旧；
- 全套单测通过（734 条）；线上包 sha256 回读一致 `3458f99d…`，7,878,295 字节。
