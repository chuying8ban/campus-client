# 校园助手 3.0.2

## 修复：小部件在系统的「支持小部件应用」列表里找不到

三处改动：

1. **补了 `previewImage`**（一张 4×2 的真实卡片预览图）。部分 MIUI/HyperOS 版本只列出
   带预览图的小部件，没有预览图的会被静默过滤掉 —— 这最可能就是列表里没它的原因。
2. **小部件名字改成「校园助手 · 今日课表」**（原来叫「今日课表」）。系统列表会按这个名字
   分组和搜索，之前找「校园助手」自然找不到。
3. App 里的手动添加说明补全成小米能走通的三条路：
   - 列表往下滑到拼音 **x**（App 桌面名是「校园」），或直接搜「校园」
   - 列表最底下的 **「安卓小部件 ›」**（非小米自带的小部件都在这个二级页里）
   - 权限：设置 → 应用设置 → 校园 → 权限管理 → 打开「桌面快捷方式」

## 顺带

小部件本身的圆角、动态主题、加桌面后的成功提示都在 3.0.1 / 3.0.0 里，不受影响。
