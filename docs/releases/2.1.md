# 校园助手 2.1

## 新功能
- 「我的 → 每日课表核对提醒」：自行开启并设置时间，提醒查看官方课表是否变化，不自动读取教务。系统省电可能延迟，需开启通知权限。
- 「我的 → 编辑课程与早晚自习」：新增、编辑、删除课程时段；修改课程名称、老师、地点、星期、精确周次和起止时间；新增及修改早晚自习。
- 手动课表只在本机保存，云端刷新不覆盖。重新导入默认保留；取消保留选项则以官方课程时段替换，自习保留。

## 修复
- 云端未提供自习安排时不再清空本机自习。
- 旧版自习已丢失的同学可在「我的」确认旧版作息后恢复；其他同学请自行新增，不应套用他人作息。
- 今日空状态改为没有已记录安排，不再断言当天确实无自习。

## 限制
晚自习沿用已有节假日规则。课程余量监控保持移除。内置教务网页排版问题仍未修复。手动课表为本机完整快照：有新调课时请再次编辑，或重新导入时明确选择替换。
