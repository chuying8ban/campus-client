# 校园助手 3.4.46

## ① 今日底部：毒鸡汤
一行小字，每次进 App 换一条。不是随机取 —— 随机必然重复；用的是**洗牌队列**：把全部条目打乱排队，一条条发，发完重洗，且新一轮第一句不等于上一句。队列落盘，杀进程重开也接着走。页面上不反复刷新（只在回到前台时重读），否则滑一下列表就换句子，看着像闪。

## ② 小组件：壁纸级动态主题（换源）
之前那 72 款（12 动效 × 6 色系）是我们**自己画的粒子场**：粒子要亮才看得见，所以底色必然深，整体就是"阴间"——参数怎么调都是黑底紫光。
动态壁纸好看的根本原因是**内容是一张好图**，动只是锦上添花。

所以直接换源：主题 = 一张在线横版插画（走自己服务器搜 safebooru，不直连境外）+ 已有的微动画笔（缓慢推近 + 轻微粒子）。6 个方向全部选白天题材：晴空 / 樱花 / 海边 / 花海 / 森林 / 雪景。

- 图按主题缓存在本地，下过一次离线可用；
- 第一次点会显示「正在准备…」，下载完自动铺上桌面；
- 下载在后台线程，provider 主线程**绝不联网**；图不在本地时不编造画面（用例钉着这条）。

## ③ 文字颜色不再连带改背景
遮罩是按"字色 vs 底色的对比度"算出来的，所以改字色必然连带改背景 —— 这就是 Bug 本身，不是副作用。已彻底关闭（App 与小组件都关）。
代价要讲清楚：字色和主题撞色时（比如深色主题配深色字）就是看不清，这是你选的，不再自动兜底。
