# 校园 App 2.1.3

## 更新内容
- 移除督促任务页面、今日任务和课程关联任务入口，保留已有收藏与历史活动记录。
- 学习库全网搜索、资源目录、我的收藏均可内置打开网页，支持后退、刷新、外部打开以及文件链接下载。
- 「全部」展示本次搜索返回并通过筛选的合集；视频、文档、练习仅筛同一合集，不代表搜尽互联网。
- 收藏支持关键词与类型筛选、打开、取消收藏确认和结果反馈。
- 搜索结果滚动后收起搜索框，可点击「修改搜索」返回；点击外部区域、搜索或切换分类取消输入焦点，保留关键词。
- 课表编辑按星期分栏展示可点击的课程/自习块；支持星期选择、常用时段、自定义时间选择器、周次网格、单/双周、全选/清空、保存与删除确认。
- 提高官方教务登录辅助文字的字号和对比度，不更改学校页面的证书校验或密码处理方式。

## 安装
已有用户：我的 → 检查更新，覆盖安装。不要先卸载，以免清除本机数据。
本项目为非官方校园工具，不自动抢课，也不提供实时官方课表同步。

没有连接真机，尚未验证真实手机上的 WebView 播放兼容性、系统下载完成和键盘动画。网页需登录或付费时不会绕过限制；普通网页下载不等于提取视频。
