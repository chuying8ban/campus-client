# 校园 App 2.1.6

这一版改的是「按返回」这件事，来自一位用华为手机的同学的反馈：手势导航从屏幕边缘划一下，App 每次都弹退出提示。

- 主界面按系统返回不再弹「退出校园助手？」对话框：先浮出一条**自动消失**的轻提示，2 秒内再按一次才退出。
- 华为等使用手势导航的手机，从屏幕边缘往内划（系统返回手势）不再被退出提示打断。
- 子页面、弹窗、学校网页历史的返回顺序不变：先按各自的语义退回上一层，只有根页面才走这条退出逻辑。

学校登录页（课表 → 更新课表）：

- 顶部工具栏改成单行，长说明与「读取课表 / 生成诊断」等操作收进「信息」入口。
- 支持上滑收起工具栏、下滑展开；工具栏显隐不再改变网页高度。
- 本机诊断仍默认关闭，需主动开启；只有预览后主动同意才会上传。

694 项自动化测试通过。退出逻辑与工具栏显隐是按真实返回事件与手势事件断言的；截图与手感属本地自动化（Robolectric）验证，真实手机上的一致性、以及东北农业大学多因子认证页面的显示仍待实机确认。

已知问题：东北农业大学统一身份认证的「多因子认证」页面在 App 内仍可能空白（系统浏览器可正常登录）。本版**没有**修复它，也不把上面的改动当作该问题的修复；排查继续。
