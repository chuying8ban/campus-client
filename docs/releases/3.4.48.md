# 校园助手 3.4.48 —— 删掉三块没用的控件

用户原话：「这里的播放速度，动态主题画质以及设为动态壁纸的功能一点用都没，直接全删了」。

删的是界面上的三块：
- **播放速度**（慢/稍慢/正常/稍快/快）
- **动态主题画质**（高画质/省内存）
- **设为动态壁纸 · 真 60 帧**（跳系统壁纸选择器的那张卡）

行为上的处理：
- 速度**固定 1×**、画质**固定高画质**，不再读旧偏好 —— 否则会出现"开关删了，但看起来还是慢 / 还是糊"（旧版本里设过的值会残留）；
- 动态壁纸那支服务代码仍在（只是没有入口了）。如果你之前真把它设成过系统壁纸，直接删掉服务会让那张壁纸变黑，所以这次只摘入口、不动服务。

透明度滑块、字体、文字颜色、壁纸级动态主题这些都还在原位。
