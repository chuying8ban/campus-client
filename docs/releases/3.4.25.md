# 校园助手 3.4.25

两个问题一起发：下载浮条压住内容、动态主题卡。

## ① 下载浮条不再"和 App 重合"

两个原因叠在一起：

1. 浮条底色用的是 `C.cardHi` —— 设计体系里的玻璃卡，**6% 白**。铺在浮条上等于半透明，
   底下的「今日日程」直接透上来，看着就是两行字糊在一块。改成不透明底色 `C.bgSoft`。
2. 浮条是 `Box` 浮层、直接盖在内容上。现在下载中给页面底部让出 82dp，
   浮条是"挤上去"的，不是"盖上去"的。

## ② 动态主题太卡

三个来源，全在 `DynPainter.frame()` 里 —— 这函数每秒跑 60 次：

- **渐变底色每帧重画**：1~3 个 `LinearGradient` + 涂满整屏。底色每帧都一样，
  现在只画一次、存成 1/4 分辨率底图，之后每帧是**一次贴图**。
- **每个光团每帧新建 `RadialGradient`**（星云 26 团 = 26 个 shader/帧）。
  改成一张预渲染的白色光晕贴图 + `PorterDuffColorFilter` 染色，一个光团 = 一次贴图。
- **每帧 new `Paint` / `RectF` / `Random`**，等于每秒给 GC 递几十个对象。
  改成 ThreadLocal 复用（小组件抽帧在 IO 线程跑，不能共用同一份）。

另外给背景加了自适应帧率：正常情况下 60fps 跟随 vsync；一旦实测帧间隔连续偏大
（>26ms，约 1 秒），自动降到 30fps，把 UI 线程预算让给列表滚动和点击 ——
**优先保手感，背景掉一点帧看不出来，列表掉帧一眼就看得出来。**
