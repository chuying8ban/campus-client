## 2.2.0 · 教务里能读出来的都读出来了

这一版只做一件事：把**已经登录过的教务**里那些"每次都要自己翻"的东西，搬进 App。

### 考试安排
导入课表时顺带把教务「考试信息」读回来：课程、考试时间、考场、类型、状态。
有考试的会显示"还有几天"，考试当天显示"今天"。入口在「我的 → 考试安排」，
今日页底部也会冒出一条倒计时（没考试就不出现）。

### 成绩
同样在导入时读回「学生成绩单」：每门课的学分、绩点、成绩，另给一份
**平均绩点（未按学分加权）**和已修学分合计。入口在「我的 → 成绩」。
新生账号暂时是空的，页面会直说"还没有"，不摆空卡片。

### 学期概览 + 学籍
课表页顶部那行现在是"12 门 · 22 学分 · 第 3~20 周"；「我的」里多一张学籍卡：
学院、专业、行政班、辅导员、学籍状态、校区。只取这六项，考生号/身份证/银行卡一律不取。

### 主题（12 套 + 自己调 + 跟随壁纸）
「我的 → 外观 → 主题色」：12 套预置、一根色相滑块自己调、或者直接按壁纸主色调配色。
所有主题都**只换强调色，不动深浅底板**——底板是对比度验过的那套，正文永远看得清。
12 套预置在深浅两种模式下都按对比度算过（`AccentsTest`），不是随手调的色号。

### 桌面小组件配色
8 套配色（默认深紫 / 纯黑 / 深蓝 / 梅紫 / 墨绿 / 暖沙 / 浅色 / 半透明）+ 自己调色相。
小组件配色**与 App 主题分开存**：桌面那张要跟壁纸搭，跟 App 里想用什么颜色是两件事。

### 今日页底部
- 有考试时：一条倒计时，点进考试安排；
- 桌面上还没放小组件时：一张邀请卡，点了直接弹系统的"添加到主屏幕"。
  系统不支持（部分国产 ROM 关了这个能力）就改成文字说明，不给点了没反应的按钮。

### 说明
考试/成绩不是实时拉取：教务这两页没有接口，只能在你「更新课表」时顺带读一次，
所以页面底部会写明"本机快照 YYYY-MM-DD"。只存在这台手机上。
