# 校园助手 3.2.1

修一个看着很难受的细节：桌面小组件的圆角只有一个角是圆的。

## 根因

两件事叠在一起：

1. 布局里的 `ImageView` 用的是 `scaleType="centerCrop"`，而帧是按卡片尺寸的 0.6 倍画的。
   launcher 报的宽度和视图真实宽高对不上时，放大填满会**把边裁掉** —— 圆角正好裁在画外，
   于是左边圆、右边是直角竖切。
2. 照片主题还压着一层整块矩形的暗蒙版（`widget_scrim`），它盖在圆角上，把四个角又填成直角。

## 改法

- **帧按卡片实际尺寸渲染**（超大时整体等比缩小到 0.7 倍，几乎看不出，内存从 ~34MB 降到 ~17MB）
- `ImageView` 改成 `fitXY`：**只拉伸、不裁切**，四个角的圆角一定在画内
- 暗蒙版**画进圆角位图里**（跟着圆角一起裁），布局里那层矩形 scrim 直接隐藏
- 纯色/渐变主题的底图本来就是现画的圆角位图，这次一并统一到同一套半径

## 验过什么
