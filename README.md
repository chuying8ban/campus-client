# 校园课表与学习客户端（Android · 中国石油大学（北京）克拉玛依校区）

一个学生自用的 Android 客户端：课表、早晚自习、任务、公共学习资源、统计看板，外加一个课位余量监控。数据以本机为主（Room 落库），联网部分连的是**中国石油大学（北京）克拉玛依校区教务系统**（`eams.cupk.edu.cn`，只读）与作者自己的一个后端服务（源码不在本仓库内）。

> **非官方项目。** 由一名学生个人开发，和学校教务处及任何学校官方系统不存在隶属、授权或背书关系；使用它可能不符合你所在学校对教务系统的使用规定，风险自负。仓库里只有源码与打好的公开安装包，不带任何个人数据、不带作者的密钥。

## 下载安装

到 [Releases](https://github.com/chuying8ban/campus-client/releases) 页取最新那个 `.apk` 装上就行（首次要允许一次"安装未知来源的应用"），不用连电脑。

装之前先确认两件事：

- **你得有这个校区的教务账号**。课表导入、余量监控、学习库这些联网功能都要用它登录；没有账号的话装了就是个空壳（离线那半——节次表、自己手录的课与任务——照旧能用）。
- **你的登录信息与数据会经过作者的后端服务**（`study.ccbase.top`）。登录时学号与教务密码会经 HTTPS 发给它，并以**加密形式保存在服务器上**（用于每天代你登录教务、读课表、跑余量监控）；你随时可以在 App 的「我的」里一键删掉这份凭据。不想把密码交给别人，就 clone 本仓、把 `apiBase` 指向你自己的服务再自己构建。

安装包用固定的一把密钥签名，所以新版能直接覆盖安装、本地数据不丢；App 里也有「检查更新」。

**监控只盯余量，不代抢**：这个功能只做余量监控与提醒，真正的选课仍由你自己在教务系统里操作。它可能因教务系统改版、限流或接口变化而失效；由此造成的任何后果（含错过选课、账号被限制）由使用者自行承担，作者不负责、也不提供保证。

## 功能

底部导航与「我的」里的入口：

| 页面 | 做什么 | 谁看得到 |
| --- | --- | --- |
| 今日 | 今天的课 + 早晚自习 + 今日任务，带课前提醒开关 | 所有人 |
| 课表 | 周视图与当天课程；从教务系统只读导入自己的课表 | 所有人 |
| 监控 | 课位余量监控、到点通知、可选课程清单（清单与网页版同一个服务） | 所有人 |
| 学习 | 阶段切换、任务卡、学习步骤与进度；顶部是「AI 规划学习计划」入口 | 所有人 |
| 学习库 | 公共资源目录：按课程 / 按类型挑链接，挑中的落成自己清单里的一条任务 | 所有人 |
| 看板 | 统计卡 + 近 14 天图 + 里程碑 + 自检 | 所有人 |
| 我的 | 账户、密码管理、网络自检、安全与隐私、授权与白名单、外观、检查更新、提建议 | 所有人 |
| 后台管理页 | 站点后台（网页版的 `/admin/`，内嵌在 App 里） | 仅作者版可见入口 |
| 查看服务器上保存的凭据 | 回显服务端保存的教务密码 | 仅作者版 |

最后两行在公开版里没有入口：**公开版不渲染后台管理页**（那页的实现与文案仍随包在内——本仓库没开代码压缩，摘不掉；但入口由构建开关关掉，普通用户看不到）；凭据回显同理，服务端也只对作者开放——那是别人自己的密码，回显一次就多一个泄露面。

另外：课前自动提醒、上课自动静音（都要系统权限，App 里有一页专门带着去开）；因为走旁加载安装，内置了应用内更新——**每次发新版，App 回到前台时会自己问一次版本，有新版本就在 App 内提示你更新**（同一个版本只提醒一次，不会反复骚扰你；「我的 → 检查更新」也可以随时手动问），点了之后下载安装包并拉起系统安装器。这条检查只看版本号，不看你的身份，细节见 [docs/RELEASING.md](docs/RELEASING.md) 的「更新通道的隐私隔离」。

**监控那一格说清楚**：它做的是监控与提醒——轮询某门课的余量、到点通知你，真正的选课动作还是你自己在教务系统里点。重建课程清单、改教务凭据这类事要回网页版，App 里那条提示就是干这个的。

**课表自己保持新鲜**：App 回到前台时会核对"今天有没有从教务读过一次"，没读过就补一次（有最小间隔，不会频繁去问教务，也不会弹错误打断你）；「我的」页显示上次成功读取的时间，你能看见数据新旧。

## 外观

「我的 → 外观」里两件事：

- **主题**：深色（默认）/ 浅色 / 跟随系统，切换立刻生效。
- **背景**：默认纯色 → 几张内置背景（程序生成的渐变图形）→ 换成你自己的图。换图走系统照片选择器，**不申请任何存储权限**；图片只落在这台手机上的 App 目录里，**不上传服务器**，随时能换回内置或纯色。铺上图之后会自动叠一层遮罩，主要文字仍然清楚；**深色主题下最小的那级灰字会比平时淡**（背景越亮越明显）——这是折算过的取舍，不是没处理。

## 构建

需要 JDK 17 和 Android SDK（版本以 `app/build.gradle` 为准）。

**必须自己给后端地址**，不给就构建失败——这是故意的：留一个默认值等于让默认包指向别人的服务器，这种错在编译期看不出来，只能等用户装上才发现。

```bash
# 命令行
./gradlew assembleRelease -PapiBase=https://your-backend.example.com
```

```properties
# 或者写进 local.properties（已 gitignore）
apiBase=https://your-backend.example.com
```

release 签名用根目录的 `campus.keystore`（不进版本库），四个参数可以用环境变量覆盖：`CAMPUS_KEYSTORE` / `CAMPUS_STORE_PASS` / `CAMPUS_KEY_ALIAS` / `CAMPUS_KEY_PASS`；也可以写在 `local.properties`（`campusKeystore` / `campusStorePass` / `campusKeyPass`）。**keystore 文件和口令都不在仓库里，所以 release 包必须用你自己的**；开发阶段跑 `assembleDebug` 即可，debug 变体走默认调试签名。

从源码构建出来的是**公开版**（不含后台入口），跟 Releases 里那个包同一套功能。

## 内置数据与隐私

`app/src/main/assets/` 里两份文件随包走：`seed.json`（节次、自习时段，外加合成演示的课程 / 任务 / 学习步骤 / 资源 / 清单 / 里程碑）与 `plan_templates.json`（计划模板）。

App 启动时**只把节次与自习时段灌进本地库**：导入前会把课程、任务、学习步骤、资源、清单、里程碑显式清空（见 `CampusApplication.kt` 里那个 `full.copy(...)`），所以文件里那几段合成内容不会落进任何人的库——每个人的任务由自己的课表推出来，谁还没同步到自己的计划，界面就明说"还没有你的计划"，宁可空着也不拿别人的数据凑。

那几段合成演示数据用来撑住界面与逻辑测试：任务文本是「演示条目NNN：…」这样的占位语，人名是「讲师甲」这类虚构称呼，院系与校区是「示例大学（北京）示例市校区」。演示数据的课程标题里会看到公开慕课平台上的课程名和来源校名（如中国大学MOOC 上各高校的课），那是为让目录看起来像真的，都是公开信息，不是本机构的课程数据。

教师姓名、教师工号、行政班号、本人课表这类**个人可识别数据在仓库里是零命中**：清理时把真实取值换成了合成值（教师一…教师十二、`XXXXXXXXXX` 之类），并有一道闸门反复扫过整棵树来把这件事固定下来。`tools/privacy_scan.py` 是发行包侧的同类检查，可以拿它扫你打出来的 APK：

```bash
python3 tools/privacy_scan.py dist/your-build.apk
```

**凭据是怎么走的，两条路不一样**：

- App 里**直连教务**那条（`EamsClient`，抓取课表等用）：密码明文不出手机，提交前用教务下发的 salt 做一次 SHA-1。
- **走作者后端登录**那条（`POST /api/v2/login`，首次引导走的就是它）：学号与密码经 HTTPS 发到 `study.ccbase.top`——客户端提交的是明文、链路是 TLS（targetSdk 34 且没开明文流量豁免，系统默认就禁 HTTP）。服务端把它以 AES-GCM 加密保存（密钥文件权限 600），用于每天代你登录教务、读课表、生成计划、跑余量监控。你随时能在「我的」里一键删掉；彻底不想给，就自己部署后端。
- 服务端**不记录口令**：校验失败的那条日志不回显提交值，登录成功或失败只记学号与来源 IP（用于失败计数与限流）。

## 来源与边界

- 目标系统：中国石油大学（北京）克拉玛依校区教务系统（`eams.cupk.edu.cn`），只读读取当前登录用户自己的课表数据。
- 本仓库是这个工具的 Android 一侧；同一作者的网页版（Python/FastAPI）不在仓库内，`apiBase` 指向的就是它，后台管理页也由它提供（入口只在作者版里）。
- 参考了什么、哪些是通用做法、哪些不能做：见 [docs/PRIOR-ART.md](docs/PRIOR-ART.md)。
- 课表规则（周次换算、streak 口径等）是与网页版逐项对齐后写进测试的，不是凭空定的——两边实现有偏差测试会红。
- 界面里的内置背景图是**程序生成的矢量图形**（本项目原创，含程序化生成 + 人工校对），不含任何第三方素材；你自己选的背景图只存在本机。
- 提建议除了 App 内那个入口，也可以直接开 [issue](https://github.com/chuying8ban/campus-client/issues)。
